# v0.6.1 — 频率扫描与弱电网筛查版本

[English](v0.6.1.md) | **简体中文**

## 范围

v0.6.1 将完整五阶段 BESS 频率扫描研究整理为可公开审查的版本。该版本保留经过验证的被控对象和控制器，增加可重复端口扰动，并发布对应的辨识、交互和时域证据。

## 新增内容

- 独立频率扫描模型和 d 轴/q 轴扰动接口。
- 0.5 Hz 至 100 Hz 的可恢复 20 点扫频。
- 完整 2 x 2 dq 导纳和正式辨识质量门槛。
- SCR 10/5/3/2 交互筛查和四档 PLL 灵敏度地图。
- 三个代表性时域工况及自动排序比较。
- 独立 10 Hz 重复性和九路信号基准等效检查。
- 双语文档、项目网页、架构图和结果图片。
- 根据已保存模型和实际结果图生成的展示级模型图、精简 GIF、高画质 MP4 与海报。
- 自动仓库证据检查和完整 R2024b MATLAB/Simulink 回归工作流。
- 精选发布 ZIP 与 SHA-256 校验文件。

## 验证状态

| 证据 | 结果 |
| --- | --- |
| 本地检查组 | 7/7 通过 |
| 标称扫频 | 20 个频点、40 次 d/q 注入运行 |
| SCR-PLL 矩阵 | 16 个运行组合、对应 640 次注入运行 |
| 10 Hz 重复性 | 幅值漂移 0%、相位漂移 0 度 |
| 基准等效 | 九路信号、实测误差为零 |
| MATLAB 静态分析 | 42 个文件、零项问题 |

## 已知结果解释

工况 B 原计划为 Moderate，但实际计算为 Higher。三个时域工况在 2.25 s 观察窗结束时均未进入 5% 稳定带。这些结果被如实保留，不会为了符合初始预期而调整。

## 发布包

发布 ZIP 包含 `v0.6.1` 标签下的受跟踪源文件，包括模型、脚本、检查、双语文档、精选图片、演示媒体、Pages 内容和工作流定义；压缩包旁同时生成对应的 SHA-256 校验文件。生成的仿真数据、缓存、编译模型文件和本地 Git 元数据均被排除。

## 兼容性

- 建议 MATLAB R2024b 或更高版本。
- 需要 Simulink、Simscape 和 Simscape Electrical。
- 无依赖仓库检查需要 Python 3.10 或更高版本。
- Image Processing Toolbox 与 Computer Vision Toolbox 为可选产品，仅用于重新生成展示媒体。
