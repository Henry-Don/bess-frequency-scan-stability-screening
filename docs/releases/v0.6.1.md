# v0.6.1 — Frequency-Scan and Weak-Grid Screening Release

**English** | [简体中文](v0.6.1.zh-CN.md)

## Scope

Version 0.6.1 packages the complete five-phase BESS frequency-scan study for public review. It preserves the validated plant and controller, adds repeatable terminal perturbation and publishes the resulting identification, interaction and time-domain evidence.

## Added

- Independent frequency-scan model and d-axis/q-axis perturbation interface.
- Resumable 20-point frequency scan from 0.5 Hz to 100 Hz.
- Complete 2 x 2 dq admittance and formal identification-quality gates.
- SCR 10/5/3/2 interaction screening and four-level PLL sensitivity map.
- Three representative time-domain cases and automated ordering comparison.
- Independent 10 Hz repeatability and nine-signal baseline equivalence checks.
- Bilingual documentation, project pages, architecture diagrams and result images.
- Presentation-quality model image, compact GIF, higher-quality MP4 and poster generated from the saved model and recorded plots.
- Automated repository-evidence checks and full R2024b MATLAB/Simulink regression workflow.
- Curated release ZIP and SHA-256 checksum.

## Validation Status

## Known Interpretation

Case B was planned as Moderate but calculates as Higher. All three time-domain cases remain outside the 5% settling band at the end of the 2.25 s observation window. These outcomes are retained rather than adjusted to match the initial expectation.

## Release Package

The release ZIP contains the tracked source tree at tag `v0.6.1`, including the model, scripts, checks, bilingual documentation, curated figures, demo media, Pages content and workflow definitions. A matching SHA-256 checksum is generated beside the archive. Generated simulation data, caches, compiled model files and local Git metadata are excluded.

## Compatibility

- MATLAB R2024b or later recommended.
- Simulink, Simscape and Simscape Electrical required.
- Python 3.10 or later for the dependency-free repository check.
- Image Processing Toolbox and Computer Vision Toolbox are optional and used only to regenerate presentation media.
