# 配置说明

[English](README.md) | **简体中文**

项目的可执行参数源为 [`scripts/init_frequency_scan.m`](../scripts/init_frequency_scan.m)。该脚本初始化经过验证的并网 BESS 被控对象，并定义扫频、质量门槛和交互研究共同使用的完整 `scan_cfg` 结构。

| 分组 | 参数内容 |
| --- | --- |
| 运行点 | 50 Hz、11 kV、有功与无功目标 |
| 频率扫描 | 0.5–100 Hz、20 个对数间隔频点和注入时序 |
| 扰动 | 0.3% d 轴电压幅值扰动及等效 q 轴相位扰动 |
| 电网与控制 | SCR、X/R 比和 PLL 增益缩放 |
| 辨识质量 | 电压残差、加权电流残差、泄漏和条件数门槛 |
| 验证 | 重复性和基准等效容差 |

只保留一个可执行参数源，可以避免独立配置副本与实际运行脚本出现参数分叉。批量运行函数以非破坏方式施加各工况的 SCR 和 PLL 覆盖值。
