# Generated Results

**English** | [简体中文](README.zh-CN.md)

MATLAB writes local simulation data and automatically generated figures to this directory. Binary result files and run-time plots are excluded from version control because they can be regenerated from the scripts under [`scripts/`](../scripts/).

Curated publication figures are stored under [`docs/images/`](../docs/images/) so the README, technical guide and project page remain reproducible and lightweight. Representative outputs include the single-frequency response, complete dq admittance, SCR interaction screening, PLL-SCR risk map and time-domain validation.

Run `tests/run_all_checks.m` to regenerate the complete validation evidence.
